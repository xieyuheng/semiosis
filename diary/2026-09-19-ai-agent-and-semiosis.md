# 动机

首先，为了方便人们上手使用 meta-lisp 等等语言，
实现一个支持 markdown 和文学式编程的极简 IDE。

- 受到 deepseek-harness 的启发，
  把这个 IDE 实现为可以在用户本地电脑打开的 Web App。

其次，尝试以皮尔士的符号学（Semiotics）为指导思想，
来实现 AI coding agent。

- 现在还有人认为 LLM 和 coding agent 不够「智能」，
  而皮尔士却认为「人的思想就是符号的连续解释过程」。
  我倒是愿意认为，人们现在的 LLM 的研究成果，
  是对皮尔士理论的证明。

- 皮尔士利用符号过程（Semiosis）来研究人类的认知过程，
  在相关的研究著述中，他给出了大量的概念，
  也许可以对于当今 AI agent 的设计有所启发。
